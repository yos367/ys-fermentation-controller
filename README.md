# YS Fermentation Controller

בקר טמפרטורה למקרר תסיסה, מבוסס ESP32. בקרה בקסקדה: חיישן PT100 בתוך הנוזל וחיישן PT100 באוויר החוזר, שליטה בברז גז חם ובגוף חימום, כשהמדחס רץ ברציפות.

חלק ממשפחת YS Brew, לצד [ys-smart-brew-controller](https://github.com/yos367/ys-smart-brew-controller).

- `DECISIONS.md` — כל ההחלטות הטכניות
- `PROGRESS.md` — יומן התקדמות
- `CLAUDE.md` — הוראות קבועות ל-Claude Code
